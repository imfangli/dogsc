# 字幕生成、校对与烧录

字幕在录制完成后的编辑器中生成。右侧参数面板顶部的 **字幕** 入口提供识别、文字和时间编辑、样式调整及 SRT 导出；窄栏时仅显示图标，悬停可查看名称。视频预览与导出共用字幕绘制管线。

## 使用流程

1. 打开录制项目，点击右侧参数面板顶部的 **字幕** 图标。
2. 选择声音来源。默认 **麦克风口播**，也可选择 **系统声音** 或 **成片混音**。麦克风来源需要项目中已经保存的麦克风音轨。
3. 可填写 **视频主题** 和 **口播稿**，帮助识别英文术语及后续 AI 纠错。
4. 点击 **生成字幕**。需要 macOS 26+、支持苹果本机识别的 Mac，以及普通话模型；模型缺失时提供下载入口。生成过程中可以取消。
5. 点击字幕条目跳到对应画面，并直接在该条目内修改文字和起止秒数。失焦或切换条目时自动保存，也可点击 **完成** 或按 ⌘↵；按 Esc 放弃本轮未保存修改。一次保存可整体撤销。时间无效或与其他字幕重叠时，草稿会留在原位提示修正。条目内也可拆分、与下一条合并或删除；拆分时可检查两条文字和分界时间。
6. 调整 **字幕样式**。默认白色字、黑色半透明圆角底板，底部居中，底板随文字收缩，最多两行。可调整文字与底板颜色、字号、底板透明度和底部距离。
7. 开启 **显示并烧录字幕** 后，视频导出会将字幕写入画面。也可点击 **导出 SRT**，输出当前剪辑对应的 UTF-8 字幕文件。
8. 在 **导出作品** 或 **导出选区** 中，可勾选 **同时导出 SRT**。字幕文件与视频或音频保存在同一文件夹，使用相同文件名；无字幕时此选项不可用。它独立于字幕烧录开关。选区的 SRT 只保留选区内的显示时间，并从 0 秒开始，与导出的媒体文件对应。

点击或拖动时间线、正常播放时，列表会高亮并滚动到当前字幕；点击字幕则将播放头移到它的起点，并在时间线上显示播放头。编辑字幕或手动浏览列表会暂停自动滚动，点击面板底部的 **跟随播放** 可恢复。主动点击时间线时先保存当前草稿，再定位到新字幕；普通播放不会打断输入。无效的时间草稿会阻止自动保存和切换，直到修正或按 Esc 取消。

字幕时间会随视频的裁剪、重排和倍速变化，已校对文字始终完整保留，不再按被剪掉的原始识别单元删字。剪短后时长不足时提示 **时间过短，需调整**，不自动延长到相邻字幕上。同一句被重排到不连续的位置时，全文只显示在最长的连续保留片段上，并提示 **重排后需复核**，其余位置不重复显示。

整条字幕对应的画面都被剪掉时，文字保留在 **未分配字幕**，暂不显示在视频里，也不导出到 SRT。点击 **放到播放头** 可恢复到空白位置，建议时长按文字长度计算，最多到下一条字幕或成片结尾；播放头已有字幕时会提示选择空白位置。恢复后仍可编辑起止秒数。主动删除的字幕不会进入未分配列表，也不会因还原画面而重新出现。

重新生成会替换已有字幕，并可撤销。AI 校对与人工编辑、样式调整也使用项目现有的保存与撤销机制。

## AI 校对

在字幕面板的设置按钮或应用设置的 **AI 校对** 中，填写 OpenAI 兼容服务的地址、模型名称和 API Key。地址可以是服务 API 前缀（例如 `https://example.com/v1`）或完整的 `chat/completions` 地址。

可先点击 **测试连接**，使用当前填写的配置发送一条简短的模型请求，不发送字幕、口播稿或主题；测试成功后再保存配置。测试与校对都可以取消。更改配置或关闭设置页会取消正在进行的连接测试。

点击 **AI 校对** 后，将字幕文字、字词 ID、口播稿和主题发送给所配置的服务；音视频文件不发送给校对服务。API Key 保存在系统钥匙串中，服务地址和模型名保存在应用偏好设置中。

校对遵循以下规则：

- 以实际口播的内容和顺序为准，稿件与主题辅助纠正错字、术语和断句，不补入漏说的内容
- 可以按原始识别的时间单元拆分、合并字幕；AI 返回稳定 ID 与文字，软件保管并推导时间，不接受 AI 自由填写的秒数
- 断句优先保证中文词语、英文名称及自然短语完整，每条以一眼可读的单行为目标，大多数约 12–20 个汉字；20 字是软上限，必要时可略超，避免半个词、悬空的从句开头和极短尾句。较长句子按自然短语拆成多条字幕，不靠在同一条中换行保留长段文字
- 允许句内标点，移除句末标点，中文与英文之间加入空格；保留词语内部的必要符号和小数
- 所有批次校验成功后直接应用为一次可撤销修改，失败时保留已有字幕
- 人工编辑过的字幕默认保留，包括人工调整过的时间，校对只处理其余字幕

较长字幕按批次处理，参考稿也使用有界的相关片段。结构不完整、ID 缺失或重复、字词顺序改变及过长的回复会被拒绝。请求取消或项目在处理期间发生相关变化后，迟到结果不会覆盖当前项目。

较长字幕默认以 256 个识别单元或 3000 个字幕字符作为请求容量上限；需要继续分批时，在容量后半段优先选择句末标点，其次是明显停顿和分句标点，单个较长的识别单元保持完整。容量上限与字幕显示长度是两回事，模型会在同一请求内生成多条字幕。

对于同一可编辑区间内仍未落在句末的请求接缝，首轮校对完成后会再发送接缝两侧各一条字幕，让 AI 同时调整两侧的文字和字词归属。复核会携带首轮已经校正的文字，保留术语修正；人工字幕之间不做跨界复核。复核窗口有容量上限，若模型反复合并导致相邻字幕过大，则保留首轮结果，不截断已校对的字幕来拼窗口。首轮和接缝复核全部成功后才整体应用，中途失败或取消不应用部分结果。这一过程改善断句条件，但语义是否正确仍取决于所配置的模型。

请求中的短数字编号由应用映射回原始字词 ID，减少模型重复输出长 ID 的负担。重新分组只改变字幕使用哪些原始时间单元，原始时间不变；字幕显示起止时间随首尾单元自动调整。单个请求允许最多 300 秒等待网络数据，总请求时限为 600 秒；校对面板显示已用时。超时不会自动重发，原字幕保留，可手动重试。

连接测试成功但长字幕校对超时时，应检查模型处理速度与接口网关的超时限制。错误提示会区分等待超时、域名解析、连接失败、证书问题、网络不可用、认证失败和错误的接口路径；不会显示 API Key 或服务返回的原始错误正文。

苹果识别提供的最小时间单元可能包含多个字；软件不会假设每个汉字都有独立时间。缺少内部识别时间的片段可换行，人工仍可指定拆分时间。

## 实现约定

- `RecorderProject.subtitles` 保存样式、参考信息、原始识别单元及字幕条目。项目 schema 为 v28，旧项目读取时默认关闭字幕；较旧应用会拒绝打开新版本项目
- 识别从当前剪辑合成中读取所选音路的 PCM，完成输入后等待苹果引擎的最终结果，再将成片时间映射到原始主录屏时间
- 识别单元保留源时间范围；字幕按当前 `TimelineMap` 投影到成片，人工调整的时间也保存为源时间范围
- 苹果识别在本机运行，使用 macOS 26 接口。备忘录跟读与字幕生成共用带引用计数的模型资源使用权，字幕生成不接管实时麦克风采集
- `FrameSceneEvaluator` 选择当前字幕，`SharedFrameRenderer` 在最终画布顶层绘制。排版及位图使用有界缓存，字幕不随录屏卡片运镜、缩放或透视变形
- 同时导出的 SRT 从导出请求中的项目快照解析，保留当前校对文字，按成片时间裁剪并归零；媒体与 SRT 均先写入临时文件，成功后一起发布，取消或写入失败不会留下半套导出。自动命名同时检查媒体及 SRT 是否已存在
- API 密钥不进入项目、错误信息或日志。识别 PCM 与转换缓冲只在内存处理；字幕文本与时间作为可编辑项目内容保存
- 应用最低要求保持 macOS 14；macOS 14–25 可以编辑、显示及导出已有字幕，生成按钮说明 macOS 26 要求

## 开发验证

```sh
swift test
```

测试覆盖源时间映射、裁剪、重排、倍速、人工修改保护、迟到结果校验、校对协议和取消、项目保存与撤销、Unicode 与标点格式、SRT，以及字幕位图、画布坐标、预览刷新和共享合成。

可使用既有的普通话合成音频测试苹果引擎的完整离线识别及原有跟读路径，测试不会请求麦克风或调用外部 AI：

```sh
DOGSC_SUBTITLE_TEST_AUDIO=/absolute/path/to/mandarin-test.aiff \
DOGSC_SPEECH_TEST_AUDIO=/absolute/path/to/mandarin-test.aiff \
swift test
```

实际服务连接需在界面配置自己的接口后验证。真机检查应覆盖长视频生成与取消、字幕文字输入及中文输入法、样式拖动、剪辑后的待复核片段、横竖画幅预览、选区视频导出、SRT 导出和项目重开。
